## DORK operations reference sheet

Create a separate sheet for the procedures and expectations used to create and maintain DORK documentation. Keep this operational guidance separate from the Framework.

Cover:
- Creating a document from the appropriate template and assigning useful metadata.
- Ownership, responsible staff, maintenance expectations, and review dates.
- Metadata definitions and the rules for changing them.
- Lifecycle transitions, especially Superseded versus Retired.
- How to identify and link the replacement of a superseded document, preserve its history and ID, and handle discovery/navigation.
- Template maintenance and authoritative content type template links.
